# Compass completion scale

Compass reaches 100% when the agreed product works and the merged build is running and verified on GitHub Pages. Award points against observed evidence for the current release. A failed or unverified item earns zero points.

| Milestone | Points | Evidence |
| --- | ---: | --- |
| Assessment and recommendations | 15 | Core flow, optional diagnostic, safety checks and evidence-linked actions work. |
| Report and local drafts | 15 | Report and print controls, local save, restore and deletion are implemented. |
| Silverspark WhatsApp | 10 | The user-controlled preview opens the designated business chat. |
| Automated checks | 15 | The current release commit passes contracts, unit tests, typecheck and static build checks. |
| Browser and PDF verification | 10 | A browser smoke test completes the flow at a narrow viewport and verifies a rendered printable report. |
| Merge | 10 | The release is present on protected main. |
| GitHub Pages deployment | 15 | Pages deploys the release artifact. |
| Live verification | 10 | The public test URL and assets load over HTTPS and the deployed assessment and report work. |
| **Total** | **100** | |

This measures delivery of the test deployment. Real-world validation and authorization for public commercial use are separate decisions.
