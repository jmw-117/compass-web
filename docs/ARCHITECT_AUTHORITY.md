# Compass delivery authority

S0–S8 are planning workstreams. Stage reviews, sign-offs and handoffs are retired. Approved product decisions, versioned domain contracts and the actual build and deployment evidence govern delivery.

Report genuine user research separately from synthetic fixtures and automated tests. Changes to scoring or risk rules require a version change, a fixture comparison and an explicit owner decision. Follow GitHub Pages terms for the authorized test deployment.
