# Compass delivery authority

Compass follows one continuous build flow from implementation to live verification. The former S0–S8 plans record historical work. Approved product decisions, the versioned domain contracts and observed build and deployment evidence govern delivery.

Report genuine user research separately from synthetic fixtures and automated tests. Changes to scoring or risk rules require a version change, a fixture comparison and an explicit owner decision. Follow GitHub Pages terms for the authorized test deployment.

See [the workstreams](stages/INDEX.md) and [the completion scale](BUILD_STATUS.md).
